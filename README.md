# par2rust

## Introduction
I wanted to try agentic AI, so I used OpenCode with Strata Qwen 3.8 Flash Next Unsloth IQ4 XS on a RTX3090 for about 20 hours (10 kWh) to convert the Original par2cmdline into a Rust project. Just for a hobby.

**par2rust** is a PAR 2.0 compatible file verification and repair tool,
ported 1:1 from the C++ command line program
[par2cmdline](https://github.com/Parchive/par2cmdline) to Rust.

It aims to be behaviourally identical to par2cmdline: the same command
line options, the same console output, the same exit codes, and the same
PAR 2.0 packet format (creation sets, verification sets and recovery
sets interoperate with files produced by par2cmdline and vice versa).

## Building

```sh
cargo build --release
```

The binary is produced as `target/release/par2rust`.

## Testing

```sh
cargo test
```

This runs the unit tests of every module plus the integration test suite
(`tests/`), which is ported from the par2cmdline test scripts and drives
the built binary against the test data in `tests/data`.
